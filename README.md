# Last Light — Zombie Survival

A small, dependency-free top-down survival game built for the browser.

## Play

Open `index.html` in a browser, or enable GitHub Pages for the repository. Survive increasingly difficult waves, kite the horde, and collect green medkits.

- **WASD** — move
- **Mouse** — aim
- **Left click** — fire
- **P** — pause

## Game design

The game is intentionally easy to pick up and hard to master: a constrained arena, escalating wave pressure, fast runner variants, limited magazine management, and risk/reward healing drops. The muted field palette and broadcast-style HUD make the survival loop feel like a tense emergency signal rather than a traditional arcade screen.
